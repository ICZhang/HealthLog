## Health Log
A health data tracker game built with HTML, CSS, and JS. Development assisted by AI.

Website Link:
https://health-log-497.vercel.app/

## Description
This is a website built for a request from an individual who needed help tracking information about their health. Data is stored and protected in Firebase DB. 
While there currently aren't any personalization features, anyone is welcome to use it if needed.

## Features
- Supports tracking for 19 aspects of daily life (Food, Water, Medication, and Bowel Movements)
- 10 dynamic graphs and calendars for trend analysis
- Editing and deleting past logs
- Email based account system

## Technologies Used
- HTML, CSS, and JavaScript
- Firebase DB
- Vercel (deployment)

## Key Skills Learned
- Improving features through closed-loop feedback
- Designing easy to read and informative graphs
- Debugging interactive programs
- Implementing a create account system based on email
- Data storage and protection
- Deploying a web application
- API Key Management (Firebase keys are expected to be public)
